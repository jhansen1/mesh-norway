# Mesh Norway

En uoffisiell iOS-app for [map.868.no](https://map.868.no), det direkte kartet over Meshtastic-nettet i Norge.
An unofficial iOS app for [map.868.no](https://map.868.no), the live map of the Meshtastic mesh in Norway.
